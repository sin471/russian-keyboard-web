# ロシア語キリル文字キーボード

ロシア語キーボードをインストールせずにキリル文字を入力できる Web アプリです。

## 使い方

1. [https://sin471.github.io/russian-keyboard-web/](https://sin471.github.io/russian-keyboard-web/) を開く
2. 画面下のキーボードをタップ／クリックして入力
3. 「コピー」ボタンでクリップボードにコピー

入力欄は直接編集も可能です。⇧ を1回押すと次の1文字が大文字、ダブルタップで Caps Lock になります。

## 機能

- ЙЦУКЕН 配列（ロシア語標準、Gboard式 11/11/9 キー）
- 長押しポップアップ：е→ё、ь→ъ、.→ , ! ? …
- 予測変換：頻度辞書（約12,000語形）による候補表示。打ち間違いのあいまい検索と、入力した単語の学習つき
- シフト・Caps Lock 対応
- コピー／クリアボタン
- PWA 対応：ホーム画面に追加してオフラインで使用可能
- レスポンシブ：スマホ（iOS / Android）・PC 両対応
- ダークモード対応

## 技術

HTML / CSS / JavaScript のみ。ビルド不要。

## 構成（ES モジュール）

- `js/main.js` — 起動・トースト・モーダル・コピー/クリア
- `js/keyboard.js` — 配列定義・キー生成・長押しポップアップ・シフト
- `js/editor.js` — テキストエリア操作（挿入・削除・入力中の単語）
- `js/predict.js` — 予測変換（候補生成・候補バー・学習）
- `js/dict.js` — 頻度辞書の読み込み・正規化・編集距離
- `js/state.js` — DOM 参照と共有状態
- `dict.txt` — 頻度辞書（約12,000語形、FrequencyWords / OpenSubtitles 由来、CC BY-SA）
